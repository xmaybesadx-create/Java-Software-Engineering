# OnlineShop — практична робота 1

Консольний інтернет-магазин на Java з Lombok.

## Запуск

Проєкт налаштовано на JDK 26 та Lombok 1.18.46. В IntelliJ IDEA відкрийте pom.xml як Maven-проєкт, виберіть JDK 26 для проєкту та Maven, оновіть Maven-залежності. Виконайте Maven clean compile, потім запустіть org.example.Main.

Через термінал з JDK 26 та Maven:

```sh
mvn clean compile
java -cp target/classes org.example.Main
```

Якщо mvn не знайдено, використовуйте вбудовану панель Maven в IntelliJ IDEA.

## Можливості

1. Каталог товарів.
2. Додавання в кошик.
3. Перегляд кошика та суми.
4. Видалення за номером позиції.
5. Оформлення замовлення.
6. Історія та деталі замовлень.
7. Пошук за частиною назви товару або категорії без урахування регістру.
0. Вихід.

Історія зберігається у orders_history.txt у поточній робочій папці. Старий формат підтримується. Якщо файл пошкоджений, програма повідомить про це та не перезапише його. Збережіть резервну копію, виправте або перейменуйте файл і перезапустіть програму.

## До захисту

- Product — дані товару; Category — категорія.
- Cart — список вибраних товарів, додавання, видалення, сума.
- Order — окремий список товарів замовлення, сума, статус і дата створення.
- OrderHistory — читання та збереження історії.
- Main — меню та обробка вводу.
- @Data генерує гетери, сетери та службові методи. Власні методи, наприклад toString, залишаються.
- @AllArgsConstructor генерує конструктор з усіма полями. @NoArgsConstructor — без параметрів.
- Конструктор Order(Cart) написаний вручну, бо містить логіку копіювання, обчислення суми та встановлення дати й статусу.
- new ArrayList<>(...) створює окремий список, але не копії самих товарів.
- readInt читає рядок і перетворює його через Integer.parseInt. При NumberFormatException просить ввести число ще раз.
- Пошук проходить каталог циклом, приводить назви та запит до нижнього регістру і використовує contains.
- addOrder повертає boolean: лише після успішного збереження Main очищує кошик.
- try-with-resources автоматично закриває файл.

## Обмеження навчальної версії

Каталог задано в коді. Ціна використовує double, як у презентації. Текстовий формат історії призначений для поточного каталогу: поля не повинні містити вертикальну риску або перенос рядка. Дати, які стара версія вже перезаписала, відновити неможливо.

## Перевірка виправлень

Виправлені вихідні файли скомпільовано компілятором Java 17 з Lombok 1.18.46. Сценарії меню, пошуку, оформлення, повторного завантаження історії, неправильного вводу, пошкодженого файлу та помилки запису перевірено. Maven-збірку саме на JDK 26 потрібно виконати на комп'ютері перед захистом.
